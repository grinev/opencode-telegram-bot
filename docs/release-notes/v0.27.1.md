## Changes

- **Unread replies** — `/recent` now marks idle sessions with a 🔔 when their latest reply has not been shown in the chat, clearing it once that reply is delivered.
- **Background reply notifications** — Notifications now show the session title and project so you can tell where a reply came from without recognising a session ID.

## Fixes

- **Opening background sessions** — The **Open session** button now switches to the session's own project and worktree, keeping progress, replies and later notifications working even after you have selected another project.
- **Live task checklists** — In full output mode, checklists now appear while `todowrite` is running, with each new snapshot below earlier output and the previous checklist collapsed to a completed/total count instead of accumulating full copies.

Full changelog: https://github.com/grinev/opencode-telegram-bot/compare/v0.27.0...v0.27.1
