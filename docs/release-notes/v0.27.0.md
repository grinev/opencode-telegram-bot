## Changes

- **Goal command support (OpenCode V2)** — Use `/goal` to enter and confirm an objective that continues on its own, with its status and Pause, Continue or Delete controls always within reach on the bottom keyboard.
- **Session search** — Find sessions by title or ID in `/sessions`, with the current session marked in both the list and search results.
- **Project search** — Find a project by name using Search in `/projects`.
- **Enable or disable recurring tasks** — Disable and re-enable recurring tasks in `/tasklist` without deleting them, with alarm and sleep icons distinguishing enabled and disabled tasks.
- **Mute background session notifications** — Silence notifications from other sessions in `/settings` while keeping replies, questions and permission requests from the selected session visible.
- **Generation speed in the footer (OpenCode V2)** — See generation speed in tokens per second and an interruption marker when an attached client stops a turn after its reply has arrived.
- **Standalone server support (OpenCode V2)** — `/opencode_start` can run a separate server without replacing or adopting your registered background service.

## Fixes

- **OpenCode startup** — `/opencode_start` now finds OpenCode in common installation directories on Linux and macOS even when a service's PATH does not include it ([@MohamedAlsayed334](https://github.com/MohamedAlsayed334)).
- **File delivery** — Receive generated files even from a read-only bot installation, without temporary-file collisions between same-named uploads ([@Realmagnum](https://github.com/Realmagnum)).
- **Detach guidance** — `/detach` now points to `/recent` so you can find and reattach to the session after detaching ([@atn18](https://github.com/atn18)).
- **Dashboard file counts** — The pinned dashboard now shows additions and deletions from OpenCode's session diff, keeping live counts consistent after switching sessions or restarting the bot.
