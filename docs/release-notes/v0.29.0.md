## Changes

- **LaTeX formulas in replies** — Display equations in formatted assistant replies now render as native Telegram math blocks without changing LaTeX examples inside code ([@Ptah9](https://github.com/Ptah9)).
- **Polish interface** — Choose **Polski** in the setup wizard to use the bot in Polish ([@kade81](https://github.com/kade81)).

## Fixes

- **Check or cancel context compaction in Telegram** — **Compact context** no longer reports success before OpenCode finishes, and while it runs you can check `/status`, cancel with `/abort`, or use `/detach` to keep working in another session ([@atn18](https://github.com/atn18)).
- **Cancel a search with `/abort`** — Use `/abort` to exit a project, session, model, command, or skill search whether you’re still entering a query or already viewing results.

Full changelog: https://github.com/grinev/opencode-telegram-bot/compare/v0.28.0...v0.29.0
