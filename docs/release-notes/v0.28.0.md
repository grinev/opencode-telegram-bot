## Changes

- **Images in replies** — Project images included in an assistant's Markdown reply now appear as native photos inside the message, including replayed replies and scheduled results.
- **Files from replies** — Project files linked in an assistant's Markdown reply now arrive as documents after the reply text, including replayed replies and scheduled results.
- **Incoming files** — Save unsupported Telegram documents locally for the agent ([@mxshooter](https://github.com/mxshooter)).
- **Command and skill search** — Use Search in `/commands` and `/skills` to find entries by name or description across the full catalog.
- **Quiet scheduled results** — Scheduled tasks can now skip result delivery with `[SILENT]` when your task prompt asks for silence if there is nothing to report.

## Fixes

- **Localization** — Fixed messages, errors, instructions and settings explanations that still appeared in English instead of the selected language in the bot and setup wizard.
- **Tool updates after outages** — Already displayed full-mode tool messages now recover their latest status after a temporary Telegram network failure, even if the run finished while offline.
- **Daemon status** — `opencode-telegram status` no longer mistakes a running daemon for a stopped one because of process-time precision differences, preserving the ability to stop it and preventing duplicate starts.
- **V1 album queue limit** — Text files sent in albums now count toward the waiting-message size limit on OpenCode V1, preventing albums from bypassing the queue budget.
