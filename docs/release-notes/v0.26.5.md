## Changes
- **Named nested launches** — when a subagent launches another one, its card's activity line now says which task it started, as in `🤖 Running Task: Count Kotlin files`, and compact mode names the launched task the same way.
- **Shorter `execute` lines** — long code in OpenCode V2 Code Mode `execute` calls is cut in the chat the same way long `bash` commands are, so a big script no longer floods the conversation.
- **No link previews under the bot's own messages** — tool lines such as `🌐 webfetch <url>`, cards, prompts, the dashboard and command replies no longer unfold a link preview, while the agent's own reply keeps it.

## Fixes
- **Voice replies** — a prompt sent by voice now gets a spoken reply for every assistant message of the turn, including the final answer, not just the first one. ([@xiehuanyi](https://github.com/xiehuanyi))
- **Background work after `/abort`** — a background subagent or command that OpenCode keeps running after `/abort` keeps its live line and timer and ends with its real result instead of showing `⏹ Interrupted` or freezing, and the `/abort` reply says how many are still running.
- **Your own pins** — switching or clearing a session now unpins only the bot's dashboard instead of every pinned message in the chat, and no longer stalls on Telegram's rate limit. ([@atn18](https://github.com/atn18))
- **Pinned dashboard on long sessions** — switching to a long session no longer stalls on loading its whole history, and the dashboard shows the session's full cost. ([@atn18](https://github.com/atn18))
- **Duplicate dashboard at startup** — the bot no longer pins two dashboards for the same session when it starts. ([@atn18](https://github.com/atn18))
- **Session preview** — picking a session in `/sessions` shows the messages already loaded instead of "No recent messages" when a later page of its history fails to load. ([@atn18](https://github.com/atn18))
- **Files on the dashboard after a switch** — on OpenCode V2, the pinned dashboard of a session picked in `/sessions` or `/recent` shows its `Files (N)` block from the first frame instead of dropping it.
