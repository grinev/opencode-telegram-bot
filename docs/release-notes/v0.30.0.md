## Changes

- **On-demand session dashboard** — The bot no longer pins the dashboard automatically; tap **📋 [project] session** on the bottom keyboard for a fresh snapshot of context usage, session cost, and changed files.
- **Project exclusions now cover sessions** — Paths already listed in `PROJECTS_EXCLUDED_PATHS` now also hide sessions in those exact directories from `/recent` and suppress their background notifications.
- **Minimal progress** — In `/settings`, set **Output mode** to **minimal** to see a single **⏳ Working** message that disappears when a reply or prompt appears or work ends.
- **Complete replies without streaming** — In `/settings`, set **Response streaming** to **off** to receive each complete reply as soon as it’s ready, without a preview or waiting for the entire turn to finish.

## Fixes

- **Live background subagent progress** — On OpenCode V2, Full and Compact progress stays live until the background subagent actually finishes, even after the parent replies or `/abort` leaves it running.
- **No separate subagent notifications** — Subagent replies, questions, and permission requests no longer trigger standalone background notifications, while questions and permission requests in the session you’re following still appear in chat.
